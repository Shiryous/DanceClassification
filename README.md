# Ballroom Dance Recognition Classifier

This is a project made for the purpose of classifying which Ballroom Dance corresponds to different songs.

## Requirements
Create a virtual environment, and install the required packages found in the requirements.txt package using:
```
pip install -r requirements.txt
```
inside the virtual environment.

## Ballroom Dataset
The training of the basic implementation was designed using the Ballroom Dataset found in the following website:
https://mtg.upf.edu/ismir2004/contest/tempoContest/node5.html

The audio files can be found in the folder:

```
data/audio_files
```
In following iterations of the project there were added more songs to enrich the dataset, but due to copyright issues they are not contained inside the repository.
